# ExpEvo — experiment code, data and reproduction package

Research artifacts for **ExpEvo**, an experience-sharing framework for continually self-improving
mobile LLM services (IEEE TMC submission). This repository contains the full experimental pipeline,
the data produced by the reported runs, and the scripts that regenerate every table and figure.

**Everything in the paper can be regenerated from the shipped data with one command, offline:**

```bash
./run_all.sh     # ~10 s: rebuilds every table and figure from the stored runs
./verify.sh      # asserts the regenerated numbers equal the values quoted in the paper
```

No LLM calls, no network, no root privileges are needed for either script. The expensive stages
(interaction, distillation, condensation, held-out answering) have already run; their outputs are
committed here, and every figure/table is a deterministic function of them.

### Backend refinement (§V-D)

Four BM25 similarity thresholds are applied **independently to the same frozen snapshot**; groups
exceeding the 3,500-word condensation budget are not merged and their members are retained, which is
why storage is non-monotonic at τ = 40.

| Setting | Storage (MB) | Indexed entries | Storage ↓ | Entry ↓ | Accuracy (%) |
|---|---:|---:|---:|---:|---:|
| Full | 4.970 | 24,000 | 0.0 % | 0.0 % | 75.68 |
| BM25 100 | 4.099 | 20,624 | 17.5 % | 14.1 % | 75.50 |
| BM25 80 | 2.937 | 15,406 | 40.9 % | 35.8 % | 75.14 |
| BM25 60 | 1.599 | 8,332 | 67.8 % | 65.3 % | 74.41 |
| BM25 40 | 1.509 | 6,529 | 69.6 % | 72.8 % | 75.27 |

Accuracy is a macro average over four subjects × 55 held-out questions × 10 samples (2,200 answers per
setting). Every paired 95 % bootstrap interval of the accuracy difference includes zero.

### Cross-client sharing (TSC revision, §V-C)

A controlled comparison on High School Geography between a **local-only** pool and a shared pool, with
the shared pool matched to the same entry count so that repository *size* is not confounded with
*sharing*. 55 unseen questions, question-level paired bootstrap.

| Policy | Entries | Clients contributing | Accuracy (%) [95 % CI] |
|---|---:|---:|---|
| Local-only | 1,500 | 1 | 80.36 [70.73, 88.37] |
| Shared-matched | 1,500 | 4 | 80.24 [71.39, 88.18] |
| Shared-full | 6,000 | 4 | 78.18 [69.27, 86.55] |

Paired differences vs Local-only: −0.12, −2.06 and −2.18 pp; every interval includes zero, so sharing
does not measurably help or hurt on this pool — the result is reported as a null effect rather than a gain.

The **complementary-coverage** variant (`runs/tsc_collaboration_hetero/`) repeats the comparison when each
client has seen a different 15 of the 60 construction questions: local pools of 375 vs an entry-matched
375-entry shared pool that covers all 60 questions.

| Policy | Entries | Clients | Construction questions covered | Accuracy (%) [95 % CI] |
|---|---:|---:|---:|---|
| Local-only | 375 | 1 | 15 | 81.45 [72.36, 89.82] |
| Shared-matched | 375 | 4 | 60 | 80.48 [71.76, 88.43] |
| Shared-full-hetero | 1,500 | 4 | 60 | 80.73 [71.82, 88.73] |

Paired Δ = −0.97, +0.24, −0.73 pp, again all including zero: broadening coverage does not shift accuracy
at this scale, so the paper can only claim *comparable* quality, not an improvement.

## Environment

Python 3.12 with numpy 2.3, pandas 2.3, pyarrow 21, matplotlib 3.10, `rank_bm25`, `requests`.

```bash
pip install -r p7/expevo_lifecycle/requirements.txt
```

Figures use Nimbus Roman (Times-compatible); without it matplotlib falls back to Liberation/DejaVu Serif
and layouts may shift slightly.

## Re-running the expensive stages (optional)

The experience corpus can be rebuilt with an API key (~26 min, ~$0.5 at the time of the run); see
`p7/expevo_lifecycle/README.md` and `.env.example`. Re-running refinement overwrites the shipped
repositories, so copy them first. Re-running the network emulation needs a Linux host with
`CAP_NET_ADMIN`, `tc`, `iproute2` and `iperf3`.

## Honesty notes

- Backend refinement happens **after** upload and is never counted as an uplink saving.
- `G_ret` is the indexed-entry count — a repository-size proxy, not measured BM25 latency.
- Fig. 6 is a trace-driven discrete-event simulation (measured payloads, synthetic Poisson arrivals),
  not a wireless MAC/PHY simulation and not a field measurement.
- The `p9/` measurement is a `tc`-shaped veth experiment, also not a field deployment.
- Accuracy differences across refinement thresholds are not statistically distinguishable with 55
  questions per subject; no "best threshold" is claimed.
